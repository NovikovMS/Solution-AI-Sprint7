## Ключевые решения

### Флагман (№ 1)

Готовой разметки «схема/не схема» нет — это не тупик, а развилка.

- **Сигнал для пилота:** путь A — слабые метки + ранжирование без учителя.
- **Качество для пилота:** путь C — вероятностная контрольная выборка из всего потока.
- **Для целевого прода — разрыв с планом закрытия:** разметка по гайдлайну силами финмониторинга, горизонт ~полгода.
- **Размещение:**
  - пилот — свой контур в облаке: наружу уходят только обезличенные агрегаты, ПДн не передаём;
  - прод — скоринг операции on-prem, а разбор назначения платежа выносим в выделенный контур, если для текста возьмём LLM.
- **Модель:** ансамбль деревьев на признаках операции, назначение платежа разбираем по ключевым словам. Конкретный алгоритм внутри семейства — за DS-командой по итогам приёмочного прогона. Для операций без истории — фолбэк на детерминированные правила.

Архитектура ML-сервиса не преждевременна, потому что сервис не выносит вердикт, а меняет порядок очереди.

### Инициатива № 2 (документы)

- **Эталон для верификации:** есть для структурированных выгрузок/Excel; для сканов — ручная разметка, которой нет.
- **Готовность:**
  - пилот — Pilot-ready (начинаем на структурированных, сканы добавляем по мере разметки);
  - прод — Gap с планом (гайдлайн + разметка ~тысяч сканов).
- **Размещение:**
  - пилот — свой контур в облаке: распознаём документ локально, дальше работает текстовая модель;
  - прод — либо всё on-prem, либо распознавание у себя, а текстовая модель в выделенном контуре.
- **Отклонено:** сквозной вызов, когда PDF целиком уходит в мультимодальную модель через публичный API — в сканах ПДн и банковская тайна.

### Инициатива № 8 (отток)

- **Данные готовы:** метка оттока извлекается из истории, ручная разметка не нужна, репрезентативность есть, смещение отбора не блокирующее.
- **Готовность:**
  - пилот — Ready;
  - прод — Pilot-ready (разрыв — бизнес-параметры: порог факта оттока, горизонт, бюджет удержания, ценность клиента).
- **Размещение:** свой контур в облаке на пилоте, on-prem в проде.
- **Модель:** ансамбль деревьев на агрегатах поведения клиента. LLM не рассматриваем — текста на входе нет, задача целиком на табличных признаках.
